# Scripts do repositório

- buscar-pubmed.mjs — ferramenta complementar para consultar o PubMed via E-utilities; não substitui a busca formal na interface oficial.
- check-prototype.mjs — verificações estáticas e estruturais do protótipo.

Os scripts são mantidos na raiz técnica para que package.json e o workflow do GitHub Actions usem caminhos estáveis. A divisão funcional está documentada acima; não mover sem atualizar scripts npm, testes e workflow.
