# Arquivo histórico

Esta área preserva documentos substituídos, versões acumuladas e materiais que não representam a orientação operacional atual. Os arquivos não foram apagados para manter rastreabilidade.

- anteprojeto/ — versões anteriores e comparações de temas.
- gestao/ — snapshots extensos do estado do projeto, roadmaps e listas de tarefas anteriores a 30/10/2026.

Use os documentos atuais em docs/gestao/ e docs/anteprojeto/. A presença de um documento no arquivo não significa que suas decisões continuem vigentes.
