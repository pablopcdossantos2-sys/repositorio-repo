# Fundamentação e evidências

Esta pasta reúne as fontes e os registros usados para construir a justificativa e fundamentar o desenho do produto.

- `levantamento-bibliografico-exploratorio-2026-10-24.md` e `revisao-rapida-evidencias-e-recomendacoes.md`: sínteses exploratórias, sem substituir uma busca formal concluída.
- `busca-bibliografica-estruturada.md` e `registros/`: estratégias, datas, contagens e evidências de execução.
- `referencias-e-busca-bibliografica.md`: referências e plano de conferência bibliográfica.
- `benchmark-recursos-existentes.md`: comparação exploratória de recursos existentes.
- `guia-execucao-pubmed-automatizada.md`: uso complementar do script PubMed; não substitui a busca na interface oficial.

Não preencher contagens, metadados ou resultados sem execução e evidência verificáveis.
