# Documentação do projeto

A documentação foi organizada por fase do projeto. Use esta página como índice; os documentos históricos permanecem disponíveis, mas não substituem as decisões vigentes registradas no anteprojeto e no estado atual.

## Fases

- [Anteprojeto](anteprojeto/README.md) — texto acadêmico, seleção, submissão e planejamento institucional.
- [Fundamentação](fundamentacao/README.md) — buscas bibliográficas, referências e análise de recursos existentes.
- [Protótipo](prot%C3%B3tipo/README.md) — escopo do produto, objetivos educativos, requisitos e histórico de implementação.
- [Avaliação](avaliacao/README.md) — testes, auditorias técnicas, instrumentos e registros de verificação.
- [Gestão](gestao/README.md) — diretrizes vigentes, roadmap e tarefas de acompanhamento.
